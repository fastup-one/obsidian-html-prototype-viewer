1Install on your computerInstalar en el ordenador

  1. Get the package onto the computer where your Obsidian lives — download it from the GitHub release, or copy it however you like (USB, cloud, email to yourself) — and unzip it.
  2. In Obsidian, open your vault and go to Settings → Community plugins.
  3. Next to «Installed plugins», click the folder icon: your vault's plugins folder opens.
  4. Copy the html-prototype-viewer-strict folder from the package into it (the whole folder).
  5. Back in Obsidian, click the reload icon (circular arrow) next to «Installed plugins».
  6. Enable HTML Prototype Viewer (Strict).
  7. Disable HTML Prototype Viewer (the original). Do not delete it: that way you can go back whenever you want.
  8. Open any HTML file in your vault: above the page there must be a shield and the word Isolated.
  1. Lleva el paquete al ordenador donde está tu Obsidian — descárgalo de la release de GitHub, o cópialo como prefieras (USB, nube, correo a ti mismo) — y descomprímelo.
  2. En Obsidian, abre tu vault y ve a Ajustes → Complementos comunitarios.
  3. Junto a «Complementos instalados», pulsa el icono de la carpeta: se abre la carpeta plugins de tu vault.
  4. Copia dentro la carpeta html-prototype-viewer-strict del paquete (la carpeta entera).
  5. Vuelve a Obsidian y pulsa el icono de recargar (la flecha circular) junto a «Complementos instalados».
  6. Activa HTML Prototype Viewer (Strict).
  7. Desactiva HTML Prototype Viewer (el original). No lo borres: así puedes volver atrás cuando quieras.
  8. Abre cualquier HTML de tu vault: encima de la página debe aparecer un escudo y la palabra Aislado.

2Your trusted HTML filesTus HTML de confianza

  • Every HTML file opens isolated: no access to your vault and no internet. For most pages that is enough.
  • If one of your HTML files needs to remember things (progress, settings), use the internet or load files from its folder: open it, click the shield at the top, then Trust.
  • If that file changes (for example, you regenerate it), it goes back to isolated and tells you. Trust it again if you still want it that way.
  • The list of trusted files, and the buttons to revoke them, are in Settings → HTML Prototype Viewer (Strict).
  • Todo HTML se abre aislado: sin acceso a tu vault ni a internet. Para la mayoría basta.
  • Si un HTML tuyo necesita recordar cosas (progreso, parámetros), usar internet o cargar archivos de su carpeta: ábrelo, pulsa el escudo de arriba y luego Confiar.
  • Si ese archivo cambia (por ejemplo, lo regeneras), vuelve a aislado y te lo avisa. Si lo sigues queriendo así, vuelve a confiar.
  • La lista de archivos de confianza, y los botones para retirarlos, están en Ajustes → HTML Prototype Viewer (Strict).
Trusting a file on the computer also approves it for your phone (see below); the phone still asks before trusting it. Confiar en un archivo en el ordenador también lo aprueba para tu móvil (ver abajo); el móvil pregunta igualmente antes de confiar.

3On your phoneEn el móvil

The plugin reaches the phone through your vault's sync; the phone's file browser cannot see the hidden .obsidian folder, so there is nothing to copy by hand. With Self-hosted LiveSync, use its Hidden File Sync limited to this plugin's folder:

El plugin llega al móvil con la sincronización de tu vault; el explorador de archivos del móvil no ve la carpeta oculta .obsidian, así que no hay nada que copiar a mano. Con Self-hosted LiveSync, usa su Hidden File Sync limitado a la carpeta de este plugin:

  1. In LiveSync's settings: General Settings → Extra menus → turn on Enable advanced features (only that one).
  2. Selector → Hidden Files: add to Target patterns ^\.obsidian(?:$|/plugins(?:$|/html-prototype-viewer-strict(?:/|$))) and to Ignore patterns ^\.obsidian/plugins/html-prototype-viewer-strict/data\.json$
  3. Sync Settings → Hidden Files → Enable Hidden File Sync: Overwrite on the computer, Fetch on the phone. Restart Obsidian when asked.
  4. On the phone: Settings → Community plugins → enable HTML Prototype Viewer (Strict) and disable the original.
  1. En los ajustes de LiveSync: General Settings → Extra menus → activa Enable advanced features (solo ese).
  2. Selector → Hidden Files: añade en Target patterns ^\.obsidian(?:$|/plugins(?:$|/html-prototype-viewer-strict(?:/|$))) y en Ignore patterns ^\.obsidian/plugins/html-prototype-viewer-strict/data\.json$
  3. Sync Settings → Hidden Files → Enable Hidden File Sync: Overwrite en el ordenador, Fetch en el móvil. Reinicia Obsidian cuando te lo pida.
  4. En el móvil: Ajustes → Complementos comunitarios → activa HTML Prototype Viewer (Strict) y desactiva el original.

Only this plugin's files travel; its settings and the phone's own trust list (data.json) stay on each device.

Solo viajan los archivos de este plugin; sus ajustes y la lista de confianza propia del móvil (data.json) se quedan en cada dispositivo.

Trust on the phone needs your computer. On a phone, a trusted file gets full access to your vault: it can read, change and delete your notes and send them over the internet. So the phone only lets you trust a file that your computer already trusted with exactly the same content (the approvals travel in approvals.json). The phone then asks again, with a checkbox, and labels it Full vault access · trusted file. If the file changes, or you revoke it on the computer, the phone shows it isolated again within 30 seconds.

La confianza en el móvil necesita tu ordenador. En el móvil, un archivo de confianza obtiene acceso completo a tu vault: puede leer, cambiar y borrar tus notas y enviarlas por internet. Por eso el móvil solo deja confiar en un archivo en el que tu ordenador ya confió con exactamente el mismo contenido (las aprobaciones viajan en approvals.json). El móvil vuelve a preguntar, con una casilla, y lo etiqueta Acceso completo al vault · archivo de confianza. Si el archivo cambia, o retiras la confianza en el ordenador, el móvil vuelve a mostrarlo aislado en 30 segundos.

Check it (2 minutes), with isolation-check.html in your vault:

Compruébalo (2 minutos), con isolation-check.html en tu vault:

  1. On the phone: 🟢 GREEN. Click the shield: a message says to trust it on your computer first.
  2. On the computer: shield → Trust. Wait for the sync.
  3. On the phone: shield → tick the checkbox → Trust. It shows 🔴 RED with the red label: expected, that is what full access means.
  4. On the computer: shield again (revoke). Within 30 seconds the phone shows 🟢 GREEN again.
  1. En el móvil: 🟢 VERDE. Pulsa el escudo: un aviso te dice que primero confíes en él en tu ordenador.
  2. En el ordenador: escudo → Confiar. Espera a la sincronización.
  3. En el móvil: escudo → marca la casilla → Confiar. Sale 🔴 ROJO con la etiqueta roja: es lo esperado, eso es el acceso completo.
  4. En el ordenador: escudo otra vez (retirar). En 30 segundos el móvil vuelve a 🟢 VERDE.

Updating: replace the three files in the computer's plugin folder with the new version's; the sync carries them to the phone. Then restart Obsidian on both devices.

Actualizar: sustituye los tres archivos de la carpeta del plugin en el ordenador por los de la versión nueva; la sincronización los lleva al móvil. Después reinicia Obsidian en los dos dispositivos.

5Checking the packageComprobar el paquete (optional · opcional)

SHA256SUMS lists the SHA-256 of every file in the package. On macOS, in Terminal, inside the unzipped folder, shasum -a 256 -c SHA256SUMS must answer OK for every line.

SHA256SUMS contiene la huella SHA-256 de cada archivo del paquete. En macOS, desde la Terminal, dentro de la carpeta descomprimida, shasum -a 256 -c SHA256SUMS debe responder OK en cada línea.

Packages built by GitHub also carry a signed build-provenance attestation, which proves the zip was built from the repository by its release workflow: gh attestation verify <zip> --repo <owner>/<repo>.

Los paquetes que genera GitHub llevan además una atestación firmada de procedencia, que prueba que el zip se construyó desde el repositorio con su workflow de release: gh attestation verify <zip> --repo <propietario>/<repo>.

In short: what it doesQué hace, en resumen

  • Isolated (always, unless you trust the file): the page cannot touch Obsidian or your vault, has no internet, cannot store data, open windows, show dialogs or download files. A line above the page explains what was blocked.
  • Trusted (only files you choose, and only while they stay unchanged): shown as in the original plugin. Above it, Not isolated · trusted file on the computer, Full vault access · trusted file on the phone.
  • Remaining risk: a page can still try to send itself to a website; that one request leaves. The plugin stops the page and shows a notice — except when it happens while the page is still loading.
  • What must never happen: a blank page with no explanation. If you see one, report it.
  • Aislado (siempre, salvo que confíes en el archivo): la página no puede tocar Obsidian ni tu vault, no tiene internet, no guarda datos, no abre ventanas, no muestra diálogos ni descarga archivos. Encima de la página se explica qué se ha bloqueado.
  • De confianza (solo los archivos que tú elijas, y solo mientras no cambien): se ve como en el plugin original. Encima aparece Sin aislamiento · archivo de confianza en el ordenador y Acceso completo al vault · archivo de confianza en el móvil.
  • Riesgo que queda: una página puede intentar irse a otra web; esa petición sale. El plugin la detiene y muestra un aviso, salvo si lo hace mientras la página aún se está cargando.
  • Lo que nunca debe pasar: una página en blanco sin explicación. Si la ves, avísame.
