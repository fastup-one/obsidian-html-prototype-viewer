1Install on your computerInstalar en el ordenador

  1. Get the package onto the computer where your Obsidian lives — download it from the GitHub release, or copy it however you like (USB, cloud, email to yourself) — and unzip it.
  2. In Obsidian, open your vault and go to Settings → Community plugins.
  3. Next to «Installed plugins», click the folder icon: your vault's plugins folder opens.
  4. Copy the html-prototype-viewer-strict folder from the package into it (the whole folder).
  5. Back in Obsidian, click the reload icon (circular arrow) next to «Installed plugins».
  6. Enable HTML Prototype Viewer (Strict).
  7. Disable HTML Prototype Viewer (the original). Do not delete it: that way you can go back whenever you want.
  8. Open any HTML file in your vault: above the page there must be a shield and the word Isolated.
  1. Lleva el paquete al ordenador donde está tu Obsidian — descárgalo de la release de GitHub, o cópialo como prefieras (USB, nube, correo a ti mismo) — y descomprímelo.
  2. En Obsidian, abre tu vault y ve a Ajustes → Complementos comunitarios.
  3. Junto a «Complementos instalados», pulsa el icono de la carpeta: se abre la carpeta plugins de tu vault.
  4. Copia dentro la carpeta html-prototype-viewer-strict del paquete (la carpeta entera).
  5. Vuelve a Obsidian y pulsa el icono de recargar (la flecha circular) junto a «Complementos instalados».
  6. Activa HTML Prototype Viewer (Strict).
  7. Desactiva HTML Prototype Viewer (el original). No lo borres: así puedes volver atrás cuando quieras.
  8. Abre cualquier HTML de tu vault: encima de la página debe aparecer un escudo y la palabra Aislado.

2Your trusted HTML filesTus HTML de confianza

  • Every HTML file opens isolated: no access to your vault and no internet. For most pages that is enough.
  • If one of your HTML files needs to remember things (progress, settings), use the internet or load files from its folder: open it, click the shield at the top, then Trust.
  • If that file changes (for example, you regenerate it), it goes back to isolated and tells you. Trust it again if you still want it that way.
  • The list of trusted files, and the buttons to revoke them, are in Settings → HTML Prototype Viewer (Strict).
  • Todo HTML se abre aislado: sin acceso a tu vault ni a internet. Para la mayoría basta.
  • Si un HTML tuyo necesita recordar cosas (progreso, parámetros), usar internet o cargar archivos de su carpeta: ábrelo, pulsa el escudo de arriba y luego Confiar.
  • Si ese archivo cambia (por ejemplo, lo regeneras), vuelve a aislado y te lo avisa. Si lo sigues queriendo así, vuelve a confiar.
  • La lista de archivos de confianza, y los botones para retirarlos, están en Ajustes → HTML Prototype Viewer (Strict).
Trust travels with the vault: a file you trust on the computer is also trusted on the phone. La confianza viaja con el vault: lo que confíes en el ordenador también será de confianza en el móvil.

The plugin reaches the phone through your vault's sync:

El plugin llega al móvil con la sincronización de tu vault:

  • Obsidian Sync: in the Sync settings, turn on syncing of installed community plugins and of the active plugin list.
  • Other sync (iCloud, Syncthing, Git…): the hidden .obsidian folder travels with the vault; nothing else to do.
  • Obsidian Sync: en los ajustes de Sync, activa que se sincronicen los complementos comunitarios instalados y la lista de complementos activos.
  • Otra sincronización (iCloud, Syncthing, Git…): la carpeta oculta .obsidian viaja con el vault; no hay que hacer nada más.

Then, on the phone: Settings → Community plugins → enable HTML Prototype Viewer (Strict) and disable the original.

Después, en el móvil: Ajustes → Complementos comunitarios → activa HTML Prototype Viewer (Strict) y desactiva el original.

The one remaining check (2 minutes):

La única comprobación que falta (2 minutos):

  1. Copy isolation-check.html into your vault and open it on the phone. It must show 🟢 GREEN.
  2. Click the shield → Trust. Tell me whether it shows 🟠 AMBER or 🔴 RED. Red means that on the phone a trusted file can see your vault: not a bug, but worth knowing when you decide what to trust.
  3. Click the shield again to revoke the trust. You can delete the file afterwards.
  1. Copia isolation-check.html a tu vault y ábrelo en el móvil. Debe salir 🟢 VERDE.
  2. Pulsa el escudo → Confiar. Dime si sale 🟠 ÁMBAR o 🔴 ROJO. Rojo significa que en el móvil un archivo de confianza puede ver tu vault: no es un fallo, pero hay que saberlo para decidir en qué confías.
  3. Pulsa el escudo otra vez para retirar la confianza. Después puedes borrar el archivo.

5Checking the packageComprobar el paquete (optional · opcional)

SHA256SUMS lists the SHA-256 of every file in the package. On macOS, in Terminal, inside the unzipped folder, shasum -a 256 -c SHA256SUMS must answer OK for every line.

SHA256SUMS contiene la huella SHA-256 de cada archivo del paquete. En macOS, desde la Terminal, dentro de la carpeta descomprimida, shasum -a 256 -c SHA256SUMS debe responder OK en cada línea.

Packages built by GitHub also carry a signed build-provenance attestation, which proves the zip was built from the repository by its release workflow: gh attestation verify <zip> --repo <owner>/<repo>.

Los paquetes que genera GitHub llevan además una atestación firmada de procedencia, que prueba que el zip se construyó desde el repositorio con su workflow de release: gh attestation verify <zip> --repo <propietario>/<repo>.

In short: what it doesQué hace, en resumen

  • Isolated (always, unless you trust the file): the page cannot touch Obsidian or your vault, has no internet, cannot store data, open windows, show dialogs or download files. A line above the page explains what was blocked.
  • Trusted (only files you choose, and only while they stay unchanged): shown as in the original plugin. Above it, Not isolated · trusted file.
  • Remaining risk: a page can still try to send itself to a website; that one request leaves. The plugin stops the page and shows a notice — except when it happens while the page is still loading.
  • What must never happen: a blank page with no explanation. If you see one, report it.
  • Aislado (siempre, salvo que confíes en el archivo): la página no puede tocar Obsidian ni tu vault, no tiene internet, no guarda datos, no abre ventanas, no muestra diálogos ni descarga archivos. Encima de la página se explica qué se ha bloqueado.
  • De confianza (solo los archivos que tú elijas, y solo mientras no cambien): se ve como en el plugin original. Encima aparece Sin aislamiento · archivo de confianza.
  • Riesgo que queda: una página puede intentar irse a otra web; esa petición sale. El plugin la detiene y muestra un aviso, salvo si lo hace mientras la página aún se está cargando.
  • Lo que nunca debe pasar: una página en blanco sin explicación. Si la ves, avísame.
